# Закат медиа (версия для Vercel)

Музыкальный журнал с админ-панелью: клиент входит по логину и паролю и сам публикует статьи. Разделы: Интервью, Биографии, Новости, Радио. Внешних пакетов нет.

## Как это устроено

Vercel не хранит файлы между запросами (диск только для чтения), поэтому статьи и обложки лежат в базе **Upstash Redis**, которая подключается к проекту в Vercel за пару кликов. Сессия входа хранится в подписанной куке, лимит неверных паролей считается в Redis.

```
├── api/index.js          # вход для Vercel: принимает все адреса сайта
├── lib/handler.js        # вся логика: страницы, админка, загрузка обложек
├── lib/store.js          # статьи и обложки
├── lib/storage.js        # Redis на Vercel, файл data/kv.json локально
├── lib/security.js       # пароли, сессии, CSRF, лимит входа, заголовки
├── lib/render.js         # HTML-шаблоны
├── public/static/        # стили и скрипты (их отдаёт сам Vercel)
├── dev-server.js         # локальный запуск
├── vercel.json
└── tests/smoke.test.js   # npm test
```

## Локальная проверка

Нужен Node.js 22 (подойдёт и 20.12 или новее).

1. `npm run setup`: введите логин и пароль (не короче 12 символов). Команда создаст `.env` и напечатает три значения для Vercel.
2. `npm run dev`, затем откройте http://localhost:3000 и http://localhost:3000/admin
3. `npm test` проверяет защиту и сценарии в трёх режимах (файл, Redis, вход через `api/index.js`).

## Загрузка на GitHub

1. На github.com нажмите «+», New repository. Название латиницей, например `zakat-media`, доступ **Private**.
2. Через браузер: Create repository, затем «uploading an existing file», перетащите **содержимое** папки проекта (не саму папку). Нажмите Commit changes. Проверьте, что появились `.gitignore` и папки `api`, `lib`, `public`.
3. Либо через терминал (нужен Git):
   ```
   git init
   git add .
   git commit -m "Первая версия сайта"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/zakat-media.git
   git push -u origin main
   ```
4. Файла `.env` в репозитории быть не должно (он в `.gitignore`).

## Публикация на Vercel

1. На vercel.com: Add New, Project, выберите репозиторий. Framework Preset: **Other**, остальное по умолчанию.
2. В проекте: **Storage, Create Database, Upstash for Redis**, подключите к проекту. Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`.
3. **Settings, Environment Variables:** добавьте `ADMIN_USER`, `ADMIN_PASS_HASH` и `SESSION_SECRET` (значения напечатал `npm run setup`). Хеш содержит знаки `$`, вставляйте его как есть, целиком.
4. **Settings, General:** Node.js Version поставьте 22.x.
5. **Deployments, Redeploy**, чтобы переменные заработали.
6. Откройте `ваш-адрес.vercel.app/admin`.

Если стили не загрузились (страница без оформления), проверьте в Settings, General, что Output Directory не заполнен или равен `public`.

## Важно про тариф

Бесплатный план Vercel Hobby разрешён **только для некоммерческого личного использования**. Для проверки админки он подходит. Сайт клиента, который зарабатывает или рекламирует бизнес, нужно держать на платном плане Pro: прочитайте условия на vercel.com/docs/limits/fair-use-guidelines.

## Что хранится и ограничения

- Статьи: в Redis одним документом. Если два человека одновременно сохранят статью, победит последний, поэтому редактировать должен один человек.
- Перед каждым сохранением предыдущая версия всех статей кладётся в список копий (последние 30). Кнопка «Скачать копию статей» в админке отдаёт текущий файл: скачивайте его раз в неделю.
- Обложки: до 600 КБ, лежат в Redis. Для большого числа картинок позже лучше подключить Vercel Blob.
- Объёмы и цены Redis смотрите в тарифе Upstash: я их не проверял.

## Безопасность

- Пароль хранится как хеш scrypt, сравнивается за постоянное время.
- Сессия в подписанной куке (HttpOnly, SameSite=Strict, Secure на Vercel), живёт 2 часа. Поэтому выйти «со всех устройств» нельзя, а смена `SESSION_SECRET` закрывает все сессии сразу.
- CSRF-токен во всех изменяющих запросах, лимит 5 неверных паролей на 15 минут по адресу.
- Заголовки: CSP без инлайн-кода, X-Frame-Options, nosniff, Referrer-Policy, Permissions-Policy, HSTS.
- Весь текст экранируется. Обложки проверяются по первым байтам (JPG, PNG, WebP), имя файла случайное.
- Если хранилище или переменные не настроены, вход закрыт, а сайт показывает демо-статьи.

## Счётчик «Сейчас на сайте»

Декоративный элемент, а не статистика. Под ним на каждой странице написано: «Счётчик демонстрационный: числа не отражают реальных посетителей сайта». Подпись убирать нельзя. Число зависит от времени суток и меняется плавно: ночью 250–500, днём 500–1250, вечером 1250–2500. Настройки в `public/static/counter-model.js`.

## Смена пароля 

`npm run setup` заново, обновите `ADMIN_PASS_HASH` (и при желании `SESSION_SECRET`) в Vercel и сделайте Redeploy.
